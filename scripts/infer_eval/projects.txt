# Not commits. `make infer-fetch` takes each project's newest commit on its
# default branch, and records exactly what it got in
# target/inference-eval/ext/fetched.json, which export_models.py copies into
# the model manifest. Reproducing an old run is
# `fetch_projects.py --pinned semantic/models/MANIFEST.json`, not a pin here.
