# lexicographic list order / min / sort (0.35) — shipped

**Theme:** CPython-style list ordering and kit that depends on it.

**Ship:** `0.35.0`

## In scope (done)

1. **`pyrs_list_cmp`** — lexicographic element order (reuses `slot_ord_cmp`)
2. **Operators** `list < <= > >=` when both sides share an orderable element type
3. **`min`/`max`** multi-arg and list form over homogeneous orderable lists
4. **`sorted` / `list.sort`** without `key=` for `list[list[…]]` (list tags in qsort)

## Residuals

- Keyed sort materializes a never-freed auxiliary keys list of length `n`
- Class `__len__` via bare `key=len` — **done in 0.36**
- Dict/set ordering still unsupported (like CPython)

## Out of scope (unchanged)

- GC, multi-inheritance, open `__dict__`, new stdlib modules, full PEP 380
